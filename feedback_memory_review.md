Always draft memory content and show it to Justin for review before writing to any file. Wait for explicit approval.

**Why:** Attribution errors compound - quotes get misattributed, context drifts under compression. Justin needs to catch these before they're filed. He has flagged that I hold this rule for a while then drop it mid-session when momentum picks up.

**How to apply:** No exceptions. Even in active sessions with fast back-and-forth, pause and show the draft. One message: "here's what I'd write - does this look right?" Then write only after approval.
