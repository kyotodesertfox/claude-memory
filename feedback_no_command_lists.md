Don't end responses with a list of 2-3 formatted shell command blocks for the user to run. It's visually cluttered.

**Why:** User finds it messy when presented with multiple choices or steps formatted as separate code blocks.

**How to apply:** State what still needs doing in plain language. If a specific command is needed, give one clean block. Let the user ask for the exact command if they want it.
